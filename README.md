# Common Lisp Exercises

Small Common Lisp programs for practicing recursion on lists, numbers and nested structures.

## Run a sample

From the repository root, load one program at a time in a Common Lisp implementation such as SBCL.

```bash
sbcl --load "for lists/summa of list.lsp"
```

Read the selected file for its function names and example inputs. The folders `for lists`, `for numbers` and `for structure lists` group the exercises by subject.
